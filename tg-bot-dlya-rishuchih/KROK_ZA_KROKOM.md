# Що зробити, щоб запустити бота — крок за кроком

* **Частина 1 — запуск на вашому комп'ютері** (зараз, ≈ 20 хв). Бот працює, поки відкрите його вікно.
* **Частина 2 — хостинг** (пізніше, ≈ 40 хв): бот працює цілодобово, незалежно від комп'ютера.

Ставте галочки (`[x]`) по ходу.

## Що вже готово і чого ще бракує

- [x] Текст оферу — у `content.yaml` (`messages` → `offer`).
- [x] 5 пакетів (START, STANDARD, AUTOMATION, PRO, MASTER) з цінами й описами — у `content.yaml` (`packages`).
- [ ] **Посилання на оплату** — пізніше. Зараз бот **інформаційний**: під описом пакета лише
      «Подивитися інші пакети». Додасте посилання в пакет — кнопка оплати з'явиться сама.
- [ ] **Контакт менеджера** в Telegram — коли з'явиться оплата (йому люди надсилатимуть квитанції).

# Частина 1. Запуск на комп'ютері

## Крок 1. Розпакуйте проєкт (5 хв)

- [ ] Завантажте **останній** архів `TG BOT DLYA RISHUCHIH.zip` із чату з Claude.
- [ ] Правою кнопкою по архіву → **«Видобути все…»** → у полі шляху вкажіть
      `C:\Users\aimas\OneDrive\Desktop\TG BOT DLYA RISHUCHIH` → **«Видобути»**.
      Якщо Windows спитає про заміну файлів — **«Замінити файли в місці призначення»**.
- [ ] Перевірте: у папці є `start_bot.bat`, `content.yaml` і папка `bot`.

## Крок 2. Токен бота (5 хв)

У вас уже є бот **@aimastery_agent_bot** — його й використаємо.

- [ ] ⚠️ Токен цього бота було надіслано в чат, тож його варто замінити: у **@BotFather** надішліть `/revoke`
      → виберіть `@aimastery_agent_bot` → BotFather видасть **новий токен**, а старий перестане діяти.
- [ ] Збережіть новий токен у надійному місці. Більше нікуди його не надсилайте (і в чат теж).

> Якщо старий бот зараз десь працює (на сервері чи в конструкторі ботів) — після запуску нового він там
> перестане відповідати: одним ботом в один момент може керувати лише одна програма.

Необов'язково: у @BotFather `/setdescription` — текст, який людина бачить до натискання Start (опишіть курс);
`/setuserpic` — аватар.

## Крок 3. Встановіть Python (5 хв, один раз)

- [ ] Відкрийте **python.org/downloads/windows** і завантажте **«Windows installer (64-bit)» для Python 3.14**
      (підійде й 3.13). ⚠️ **Python 3.15 не беріть** — бібліотека aiogram його ще не підтримує.
- [ ] Запустіть встановлювач, **поставте галочку «Add python.exe to PATH»** → **Install Now**.

## Крок 4. Запустіть бота (5 хв)

- [ ] У папці проєкту двічі клацніть **`start_bot.bat`**.
      Якщо Windows покаже «Windows захистив ваш ПК» — **«Докладніше»** → **«Виконати все одно»**.
- [ ] Перший запуск: 1–2 хвилини встановлюються бібліотеки, потім відкриється **Блокнот** із файлом `.env`.
- [ ] Вставте новий токен одразу після `BOT_TOKEN=` (без пробілів і лапок), щоб вийшло так:
      `BOT_TOKEN=123456789:AAH…` → збережіть (`Ctrl+S`) → закрийте Блокнот.
- [ ] Бот запуститься. У вікні має з'явитися рядок `Бот @aimastery_agent_bot запущено`.
      Не закривайте вікно, поки тестуєте: закрили вікно — бот зупинився.

Наступні запуски — знову подвійний клік по `start_bot.bat` (уже без встановлення і без Блокнота).
Якщо щось пішло не так — у вікні українською написано, що саме (наприклад, «BOT_TOKEN не задано»).

## Крок 5. Перевірте в Telegram (10 хв)

- [ ] Відкрийте **@aimastery_agent_bot** → **Start** (або надішліть `/start`): має прийти офер,
      знизу — «Пропозиція для рішучих. Діє 24 години», таймер «Залишилось: 24 год» і кнопка **«Обрати пакет»**.
- [ ] «Обрати пакет» → 5 кнопок із цінами → виберіть пакет → опис → «Подивитися інші пакети».
- [ ] Через хвилину-дві таймер в офері сам зміниться на «23 год 59 хв».
- [ ] Перевірка «таймер не скидається»: закрийте вікно бота, знову запустіть `start_bot.bat`, надішліть `/start` —
      залишок часу той самий, а не нові 24 години.
- [ ] Перше нагадування прийде через 2 години після першого `/start` — якщо бот у цей час запущений.

> Ваш особистий таймер запускається лише один раз. Щоб пройти все «з нуля»: зупиніть бота, вставте
> `%LOCALAPPDATA%\TgBotDlyaRishuchih` в адресний рядок Провідника і видаліть там `bot.db`
> (і `bot.db-wal`, `bot.db-shm`, якщо є).

## Крок 6. Доповніть контент (10–20 хв)

- [ ] Відкрийте `content.yaml`: правою кнопкою → **«Відкрити за допомогою»** → **Блокнот**
      (зручніше — безкоштовні Notepad++ або VS Code).
- [ ] **Посилання на оплату** (коли будуть): у пакет додайте рядок `payment_url` — кнопка оплати з'явиться сама:
      ```yaml
        - id: start
          name: "⚡️ START"
          price: "3 900 грн"
          payment_url: "https://…справжнє посилання на оплату START…"
      ```
- [ ] **Контакт менеджера** (разом з оплатою): у `messages` → `payment` замініть рядок «✏️ … @manager», наприклад:
      `Квитанцію про оплату надішліть менеджеру: @ваш_менеджер`.
- [ ] За бажанням — тексти нагадувань (`reminders`) і що буде після 24 годин
      (`settings` → `packages_after_expiry`, пояснення — у коментарях у файлі).
- [ ] Збережіть (`Ctrl+S`) і двічі клацніть **`check_content.bat`**: «OK» — усе добре, «ПОМИЛКА» — там написано,
      яке поле виправити.
- [ ] Закрийте вікно бота і запустіть `start_bot.bat` знову — бот підхопить нові тексти.

**Правила, щоб не зламати файл:**
- Не натискайте **Tab** — лише пробіли. Новий рядок тексту починайте з такого самого відступу, як сусідні.
- Змінюйте лише текст праворуч від двокрапки або під `|`. Назви полів (`name:`, `price:` …) не чіпайте.
- Короткі значення — у лапках: `"3 900 грн"`. Лапки всередині тексту — «ялинки» `« »`.

# Частина 2. Хостинг (пізніше): бот працює цілодобово

Подробиці й типові проблеми — у [`DEPLOY.md`](DEPLOY.md).

## Крок 7. Завантажте проєкт на GitHub (10 хв)

- [ ] github.com → **+** → **New repository** → назва `tg-bot-dlya-rishuchih` → **Private** → **Create repository**.
- [ ] **uploading an existing file** → виділіть усе в папці проєкту (`Ctrl+A`) і перетягніть у браузер.
      **Не перетягуйте файл `.env`** (у ньому токен) і папки `.venv`, `data`, якщо вони є.
- [ ] **Commit changes**. У корені репозиторію мають бути `content.yaml`, `Dockerfile` і папка `bot`.

## Крок 8. Сервіс на Railway (5 хв)

- [ ] railway.com → **Login** → **Continue with GitHub** → **New Project** → **Deploy from GitHub repo** →
      `tg-bot-dlya-rishuchih` (якщо його немає в списку — **Configure GitHub App**).
- [ ] Помилка «BOT_TOKEN не задано» після першої збірки — нормально, токен додамо далі.

## Крок 9. Токен і постійний диск (5 хв)

- [ ] **Зупиніть бота на комп'ютері** (закрийте вікно `start_bot.bat`): дві копії з одним токеном конфліктують.
- [ ] Сервіс → **Variables** → **New Variable**: `BOT_TOKEN` = токен → **Add** → **Deploy**.
- [ ] `Ctrl+K` → `Volume` → **New Volume** → сервіс бота → **Mount Path** `/data` → **Create** → **Deploy**.
      Без диска після кожного оновлення таймери почнуться заново.

## Крок 10. Тариф (5 хв)

- [ ] Пробного періоду ($5, 30 днів) вистачить для перевірки; для постійної роботи — план **Hobby** ($5/міс)
      у налаштуваннях акаунта Railway + картка.
- [ ] Після переходу на Hobby: сервіс → **Settings** → **Restart Policy** → **Always**.

## Крок 11. Перевірка на хостингу (10 хв)

- [ ] **Deployments** → **View logs**: `Бот @… запущено. База даних: /data/bot.db` і без попередження
      «…БЕЗ постійного диска…».
- [ ] У Telegram: `/start` → офер, пакети, оплата.

> Користувачі, які натискали `/start` на комп'ютерній версії, на хостингу почнуть «з нуля»:
> база на комп'ютері і на хостингу — різні.

## Крок 12. Менеджер і статистика (необов'язково, 5 хв)

- [ ] Менеджер: **Start** у боті → `/myid` → число. Ви: `/myid` → своє число.
- [ ] Railway → **Variables**: `MANAGER_CHAT_ID` = число менеджера, `ADMIN_IDS` = ваше → **Deploy**.
      (На комп'ютері — ті самі рядки у файлі `.env`.)
- [ ] Менеджер отримує «💳 Запит посилання на оплату» з іменем і пакетом, вам доступна команда `/stats`.

## Крок 13. Запуск і щоденна робота

- **Посилання для реклами:** `t.me/aimastery_agent_bot`; для різних каналів — `t.me/aimastery_agent_bot?start=instagram`,
  `?start=tiktok`: `/stats` покаже, звідки прийшли люди.
- **Змінити тексти, ціни, посилання:** GitHub → `content.yaml` → ✏️ → **Commit changes** → за 2–4 хв нова версія,
  таймери людей не скидаються. З помилкою у файлі нова версія не запуститься, стара працюватиме далі.
- **Оплати:** бот оплату не перевіряє; менеджер бачить оплати у платіжній системі й видає доступ вручну.
