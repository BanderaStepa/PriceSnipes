# План розробки

## Правила роботи

1. Розробка йде **маленькими етапами**. Кожен етап завершується так:
   код → тести (`python -m pytest`) → оновлені `PROGRESS.md` і `TODO.md` → `git commit` з назвою «Етап N: …» → `git push`.
2. **Перед продовженням роботи** (нова сесія, новий день):
   прочитати `CLAUDE.md`, `PROGRESS.md`, `TODO.md`, цей план і `ARCHITECTURE.md`,
   перевірити останній коміт: `git log -3 --stat -- .` (з цієї папки).
   Останній коміт «Етап N» означає, що етап N завершено і перевірено.
3. Якщо закінчується контекст або ліміт — **зупинитися на завершеному етапі**:
   закомітити, записати в `PROGRESS.md`, що зроблено і з чого почати далі.
4. Усі тексти для користувача — лише в `content.yaml`. Стан — лише в SQLite.
