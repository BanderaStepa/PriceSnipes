# Telegram-бот «Для рішучих»

Бот продає курс через персональну пропозицію, яка діє 24 години:
`/start` → офер із таймером → «Обрати пакет» → опис пакета → посилання на оплату.
Протягом 24 годин бот надсилає нагадування з залишком часу, потім пропозиція згорає.
Оплата не перевіряється: доступ до курсу менеджер видає вручну.

> **Статус:** у розробці. Поточний етап і наступні кроки — у [`PROGRESS.md`](PROGRESS.md).

## Документи

| Файл | Що всередині |
|---|---|
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Архітектура, технології, база даних, хостинг, обробка помилок |
| [`DEVELOPMENT_PLAN.md`](DEVELOPMENT_PLAN.md) | Етапи розробки і правила роботи |
| [`PROGRESS.md`](PROGRESS.md) | Що вже зроблено і перевірено |
| [`TODO.md`](TODO.md) | Відкриті задачі та що потрібно від замовника |
| `content.yaml` | Усі тексти, пакети, ціни, посилання, нагадування, кнопки (з'явиться на етапі 1) |
| `DEPLOY.md` | Покрокове розміщення на хостингу (з'явиться на етапі 7) |
